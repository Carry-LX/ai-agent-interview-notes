## 四条主线

1. **产品与知识供给**：数字分身绑定 owner；定期扫描授权数据源，把材料蒸馏成知识包、SOP / Skill。
2. **事件唤醒与状态流转**：消息、外部请求、持续追踪以事件进入；Runtime 唤醒 Manager / 执行 Agent；等待、恢复、验收都有状态。
3. **多 Agent 分工与协作**：Discovery / Manager / Coordinator / Executor；接纳 ≠ 派发，提交 ≠ 完成；群聊协作与终验责任。
4. **稳定性与存算分离**：Broker 存协作日志、队列和回执；群级存储存黑板与文件快照；Runtime 本地计算，私有状态留在 owner。

## 怎么让 AI 用这份资料

见 [AI-PROMPTS.md](AI-PROMPTS.md)。最短的用法：

```text
阅读本仓库。基于 01/03/04/08，生成 30 个面试问题：
- 10 个架构与设计
- 8 个协作与状态
- 6 个稳定性与存算分离
- 6 个个人贡献与取舍
每个问题给出：考察点、STAR 回答草稿、3 层追问、可能的反例。
严格区分“仓库里的事实”和“你的推断”，不要编造数字。
```

- 第三方文章观点归原作者，以公开链接为准。
